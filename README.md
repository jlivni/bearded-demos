bearded-demos
=============

Small map/weather demos, hosted on GitHub Pages: http://jlivni.github.io/bearded-demos/

- `snow.html` (the index) - Tahoe road webcams and conditions links, Northlake/Southlake
- `photomap.html` - geotagged photos from Flickr and Wikimedia Commons on a Leaflet map

Photomap's Flickr key goes in `config.js` (gitignored): `window.FLICKR_KEY = "...";`
Wikimedia Commons needs no key.
